Instalar o GTM no site
Referência em Saúde

Passo a passo para adicionar o Google Tag Manager em referenciaemsaude.com.br. Os dois códigos abaixo precisam entrar em todas as páginas do site.

ID do contêiner: GTM-M3VLJ6QP
Os dois códigos

Copie os códigos do GTM

São dois trechos. O primeiro vai no topo do <head>; o segundo, logo depois que o <body> abre. Use o botão "Copiar" de cada um.

1

Código do cabeçalho

cole o mais alto possível dentro do <head> 
<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-M3VLJ6QP');</script>
<!-- End Google Tag Manager -->
2

Código do corpo

cole imediatamente após a tag de abertura <body> 
<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-M3VLJ6QP"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->
Passo a passo

Escolha o cenário do seu site

O site pode ter sido feito de formas diferentes. Siga o bloco que corresponde ao seu caso.

🟦

WordPress

Mais comum

Jeito mais simples: um plugin que insere os dois códigos automaticamente só com o ID.

  1. No painel do WordPress, vá em Plugins → Adicionar novo.
  2. Busque por GTM4WP (ou "Google Tag Manager for WordPress", do autor Thomas Geiger). Clique em Instalar e depois Ativar.
  3. Vá em Configurações → Google Tag Manager.
  4. No campo Google Tag Manager ID, cole GTM-M3VLJ6QP e salve.
  5. Pronto. O plugin coloca os dois códigos em todas as páginas sozinho.
Alternativa sem o GTM4WP: instale o plugin WPCode (Insert Headers and Footers). Vá em Code Snippets → Header & Footer, cole o Código 1 no campo "Header" e o Código 2 no campo "Body", e salve.
🟪

Elementor

O Elementor Pro tem um recurso de código personalizado que aplica em todo o site.

  1. No painel do WordPress, vá em Elementor → Custom Code (requer Elementor Pro).
  2. Clique em Adicionar novo, dê um nome (ex.: GTM Head).
  3. Cole o Código 1 e defina a localização como <head>. Publique aplicando em todo o site.
  4. Crie outro código, cole o Código 2 e defina a localização como Após a tag <body>. Publique.
Sem o Elementor Pro: use o plugin WPCode descrito no bloco do WordPress. O Elementor gratuito não insere código no <head> globalmente.
🤖

Sites feitos por IA (Lovable, Claude, Cursor, v0, Bolt)

Se o site foi criado por uma ferramenta de IA, é só pedir para ela inserir os códigos. Copie o pedido abaixo e cole no chat da ferramenta.

Adicione o Google Tag Manager em todas as páginas do site.

1) Cole este bloco o mais alto possível dentro da tag <head>:
<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-M3VLJ6QP');</script>
<!-- End Google Tag Manager -->

2) Cole este bloco imediatamente após a tag de abertura <body>:
<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-M3VLJ6QP"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->

Se o projeto for React/Next.js, garanta que o primeiro bloco carregue no
<head> de todas as páginas e o segundo logo após o <body> abrir.
Dica: depois que a IA aplicar, peça para ela publicar / fazer deploy do site. O GTM só passa a funcionar na versão publicada, não só no preview.
Confirmação

Como testar se funcionou

Depois de instalar e publicar o site, confirme que o GTM está ativo.

  1. No painel do Google Tag Manager, clique em Visualizar (Preview) e digite o endereço https://referenciaemsaude.com.br.
  2. Se o Tag Assistant conectar e mostrar o contêiner GTM-M3VLJ6QP, está funcionando.
  3. Alternativa rápida: instale a extensão Tag Assistant no Chrome, abra o site e veja se o contêiner aparece como ativo.
  4. Feito isso, é só Enviar / Publicar o contêiner dentro do GTM para as tags entrarem no ar.
